Validasi PLN Kini Tersedia di Rajacek

27 Oktober 2026 · Rajacek

Rajacek kini memvalidasi empat produk lewat satu layanan: rekening bank, e-wallet, WhatsApp, dan ID pelanggan PLN. Validasi PLN melengkapi rangkaian cek yang selama ini tersedia, sehingga kebutuhan memastikan identitas sebelum transaksi kini mencakup tagihan listrik juga.

Apa itu validasi PLN?

Validasi PLN adalah proses memastikan ID pelanggan PLN sesuai dengan nama pemiliknya sebelum pembayaran atau transaksi dilakukan. Dengan memeriksa ID terlebih dahulu, Anda terhindar dari salah kirim ke ID yang salah karena salah ketik, dan memiliki kepastian tentang pemilik ID yang dituju.

Cara cek ID pelanggan PLN

  1. Buka portal member Rajacek dan pilih produk PLN pada menu Coba Cek.
  2. Masukkan ID pelanggan PLN sepanjang 11–12 digit.
  3. Lihat hasilnya: nama pemilik serta info tarif dan daya bila tersedia.

Untuk integrasi sistem, cek PLN tersedia lewat API pada endpoint validasi PLN dengan field ID pelanggan. Detail lengkapnya ada di dokumentasi validasi PLN.

Apa yang ditampilkan hasil cek?

Hasil cek menampilkan nama pemilik ID pelanggan, serta info tarif dan daya bila tersedia. Bila ID tidak cocok, hasilnya dinyatakan tidak valid — sehingga Anda tahu sebelum melanjutkan transaksi.

Produk validasi Rajacek

Selain PLN, Rajacek memvalidasi rekening bank — baca juga Validasi Nomor Rekening: Pengertian, Cara Kerja dan Manfaat — serta e-wallet dan nomor WhatsApp. Semuanya tersedia lewat satu API dan satu portal member.

Pertanyaan yang sering diajukan

Apa yang dibutuhkan untuk cek PLN?

ID pelanggan PLN sepanjang 11–12 digit. Masukkan ID tersebut di portal member atau lewat API, dan hasilnya menampilkan nama pemilik bila ID valid.

Apa yang saya dapat dari hasil cek PLN?

Nama pemilik ID pelanggan, serta info tarif dan daya bila tersedia. Bila ID tidak cocok, hasilnya dinyatakan tidak valid.

Apakah cek PLN bisa lewat API?

Ya. Kirim ID pelanggan lewat endpoint validasi PLN dan lihat detailnya di dokumentasi.
