Pertanyaan umum

Yang perlu diketahui sebelum mulai.

Apakah Rajacek sudah bisa dipakai untuk produksi?

Ya. Rajacek berjalan sebagai layanan produksi dan memproses validasi nyata setiap hari. Setiap API key memiliki kuota dan rate limit sendiri, dan seluruh riwayat cek tersimpan untuk audit.

Bank dan e-wallet apa saja yang didukung?

111 kode bank Indonesia serta e-wallet populer — DANA, GoPay, OVO, LinkAja, ShopeePay, dan lainnya. ID pelanggan PLN (11–12 digit) juga bisa divalidasi, dengan nama pelanggan beserta tarif/daya. Daftar lengkap tersedia di endpoint GET /v1/banks dan halaman dokumentasi.

Bagaimana API menangani request yang diulang?

Kirim Idempotency-Key yang sama saat retry: respons pertama diputar ulang tanpa memotong kuota dua kali. Jika Anda tidak mengirimnya, server membuatkan kunci otomatis — request tetap diproses, tetapi pengiriman ulang dihitung sebagai cek baru.

Data apa yang disimpan Rajacek?

Setiap cek tercatat di riwayat: produk, hasil, latensi, dan target dalam bentuk tersamar. Nomor asli tidak pernah ditampilkan di panel, riwayat, maupun respons member lain.
