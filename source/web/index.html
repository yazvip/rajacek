Endpoint pihak ketiga

Kelola endpoint provider

Atur koneksi dan petakan respons JSON provider ke format Rajacek. Biarkan kredensial kosong untuk mempertahankan rahasia lama.

Metode & param queryHanya untuk mode Generic.

POST mengirim body JSON {product, target, provider_hint, request_reference}. GET mengirim kode + nomor sebagai query string dengan nama param di bawah; kunci query opsional — kosong berarti kunci hanya lewat header di atas.

Mapping respons JSONSesuaikan path dengan respons provider.

Gunakan path bertitik seperti data.account.name atau indeks seperti data.items[0].status. Nilai status dipisahkan koma dan tidak peka huruf besar/kecil.

Mapping kode pihak ketigaKode member → kode yang dikirim ke provider ini.

Hanya untuk e-wallet mode Generic. Terisi awal dengan kode member sendiri (dikirim apa adanya); ubah sesuai kode di pihak ketiga. Contoh: isi dana009 di baris DANA agar request member dana terkirim sebagai dana009. Baris yang dikosongkan berarti dikirim apa adanya.

Mapping kode bank pihak ketigaKode member → kode yang dikirim ke provider ini.

Hanya untuk bank mode Generic. Tambah baris hanya untuk kode yang berbeda dari kode member; tanpa baris, kode dikirim apa adanya. Contoh: baris 014 → BCA agar request member 014 terkirim sebagai BCA.
